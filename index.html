INGAT KEMBALI

Apa itu If-Else?

IF (JIKA)

Jika kondisi terpenuhi, jalankan kode.

ELSE IF (JIKA)

Jika kondisi sebelumnya tidak terpenuhi, jalankan kode.

ELSE (JIKA TIDAK)

Jika kondisi sebelumnya tidak terpenuhi, jalankan kode terakhir.
